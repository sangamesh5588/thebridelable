> **The Bride Label** is a luxury digital storefront and bridal couture catalog engineered with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. It delivers an elegant high-conversion shopping experience featuring interactive product filtering, lookbook galleries, and responsive client inquiry workflows.

---

## ✨ Features

- 💎 **High-Resolution Lookbook:** Fluid product gallery showcasing handcrafted bridal gowns, lehengas, and designer collections.
- 🔍 **Interactive Filtering & Taxonomy:** Filter collections by occasion, fabric, silhouette, and price range with instant state reactivity.
- 📱 **Mobile-Optimized Luxury UI:** Designed for effortless browsing across mobile touchscreens and ultra-wide desktop monitors.
- ⚡ **Lightning Fast Build:** Sub-second hot module replacement (HMR) powered by Vite and modern ES modules.

---

## 🚀 Quick Setup & Installation

### 1. Clone the Repository
```bash
git clone https://github.com/sangamesh5588/thebridelable.git
cd thebridelable
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
